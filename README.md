# COS 201 – Computer Programming I
## Week 3 Assignment

### Programs submitted
1. `SimpleCalculator.java` – Performs addition, subtraction, multiplication and division.
2. `AverageCalculator.java` – Calculates the average of numbers entered by the user.
3. `ItemCost.java` – Calculates the total cost using quantity multiplied by unit cost.

### Requirements
- Java Development Kit (JDK) installed.
- A terminal or command prompt.

### How to compile
Open a terminal in the folder containing the Java files and run:

```bash
javac SimpleCalculator.java AverageCalculator.java ItemCost.java
```

### How to run each program

Run the simple calculator:

```bash
java SimpleCalculator
```

Run the average calculator:

```bash
java AverageCalculator
```

Run the item cost calculator:

```bash
java ItemCost
```

### Notes
- The programs accept input from the keyboard.
- The calculator checks for division by zero and invalid operators.
- The average calculator asks how many numbers will be entered.
- The item cost calculator multiplies quantity by unit cost.
- These implementations use standard assumptions because the supplied assignment notice lists the filenames but does not include detailed problem specifications.
